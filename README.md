# windows-security-monitoring-lab

## Overview
This repository documents my personal learning project focused on Windows security monitoring and log analysis.
Used products are Sysmon, mitmproxy, Python, and Splunk, etc..

## Objectives
- Understand Windows event logging using Sysmon.
- Explore HTTP/HTTPS traffic inspection using mitmproxy.
- Collect and analyze security logs using Splunk.
- Develop practical skills in security monitoring and detection enginnering.

## Technologies
- Windows
- Sysmon
- mitmproxy
- Splunk
- Python

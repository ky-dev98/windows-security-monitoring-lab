# windows-security-monitoring-lab

## Overview
This repository documents my personal learning project focused on Windows security monitoring and log analysis.
Used products are Sysmon, mitmproxy, Python, and Splunk, etc..

## Objectives
- Understand Windows event logging using Sysmon.
- Explore HTTP/HTTPS traffic inspection using mitmproxy.
- Collect and analyze security logs using Splunk.
- Develop practical skills in security monitoring and detection enginnering.

## Technologies
- Windows
- Sysmon
- mitmproxy
- Splunk
- Python

## Documentation
- Sysmon monitoring
- HTTP/HTTPS monitoring
- Splunk integration
- Detection

## Detection Engineering

This project also includes detection rule development
and validation using Splunk Enterprise.

Detection rules are developed using SPL, with plans to
explore Sigma rules for SIEM-independent detection logic.

## Disclaimer
This repository is an independent personal lab project.
All examples are intended for educational purposes.
